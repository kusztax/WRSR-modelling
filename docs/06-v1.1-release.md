# v1.1 – tartalom és tesztlista

## Tartalom
- A visszatartott tehervonat jelzője pirosat mutat (`signal_aspect = 1` az
  alapértelmezés). Elengedéskor a mod a játék saját újraszámolójával frissíti
  a jelzőt; 2 mp-enként takarít minden olyan pirosat, amelyik vonatát 3 mp
  óta nem látta.
- Harmadik gomb a Szkriptek menüben: beragadás elleni idő, körbe léptetve
  30 → 60 → 90 → 120 → 180 → 30 mp. Mentésenként: egy
  `RailPriority_Hold<N>Flag.txt` jelzőszkript fut (egyszerre egy). Ha egyik
  sem fut, az ini `max_hold_s` értéke érvényes (60), és az első nyomás 90-et ad.
- Az értesítés a játékos nyelvén írja ki a választott időt
  (szöveg-azonosítók 1957011–1957015, a DLL szolgálja ki).
- Verzió: 1.1.0.

## Tesztlista
1. [ ] Napló: `prio  Scripts menu: jam guard from the ini`, majd gombnyomásra
   `jam guard 90 s`, `120 s`, `180 s`, `30 s`, `60 s`; értesítés a helyes
   számmal, magyarul.
2. [ ] Mentés → újratöltés: a napló a választott időt mutatja (nem az ini-t).
3. [ ] 30 mp-re állítva egy szándékosan beragasztott személyvonat mellett a
   tehervonat ~30 mp után `TIMEOUT`-tal elindul.
4. [ ] 10–15 perc normál játék: nincs beragadt piros jelző (a napló minden
   `aspect RED` sorához tartozik később `aspect FREE`).
5. [ ] Régi (1.0-s) mentés betöltődik; jelzőszkript nélküli mentésben az ini
   értéke él.
6. [ ] Mod nélkül: jelzőszkriptes mentésnél hiányzó elem → piros X → betölt.
7. [ ] Windows / RML (ha van rá idő).
